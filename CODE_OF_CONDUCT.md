# Code of conduct

## The short version

Be decent to people. Criticise the work, not the person.

## What is expected

- Assume the other person is acting in good faith.
- Keep disagreement about the substance: the method, the numbers, the code.
  "This comparison is confounded because X" is welcome. "You clearly do not
  understand RL" is not.
- Accept correction gracefully, and correct others the way you would want to
  be corrected.
- Respect that people here have different levels of experience. A question
  that seems basic to you is not a reason to be dismissive.

## What is not acceptable

- Harassment, insults, or personal attacks, in issues, pull requests, commit
  messages, or anywhere else connected to this project.
- Comments directed at someone's identity rather than their argument.
- Sexual language or imagery, and unwelcome attention of any kind.
- Publishing someone's private information without their permission.
- Sustained disruption: reopening settled arguments, brigading a thread,
  derailing a review.

## Scope

This applies in every space this project uses, and when someone is
representing the project in public.

## Reporting

Open an issue if it is something the whole project should see, or contact the
repository owner directly through their GitHub profile if it is not. Reports
are read and acted on. Reporting something in good faith will never count
against you, whatever the outcome.

## Enforcement

The repository owner decides what happens, and will say why. Depending on
severity and whether it is repeated, the response ranges from a private word,
to a public correction, to a temporary or permanent ban from the project.

This document is a plain-language code of conduct written for this
repository. If you want the widely used standard instead, see the
[Contributor Covenant](https://www.contributor-covenant.org).
